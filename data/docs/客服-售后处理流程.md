# 售后处理流程

## 总原则

先安抚情绪，再解决问题。顾客带着不满来沟通时，**不要在第一步就讲解规则**，规则留到方案环节再说明。整个流程应在 24 小时内给出明确处理方案。

## 标准四步流程

### 第一步：安抚与共情（立即）

倾听顾客描述，不打断，先道歉。参考《客服-标准话术》中的售后安抚话术。

### 第二步：核实信息（5 分钟内）

礼貌索取必要信息，**一次问清**，不要让顾客反复补充：

- 订单号
- 问题商品的具体情况（腐烂、破损、分量不足、错发）
- 凭证照片：整体照与细节照各一张，**自然光下拍摄**

凭证的拍摄要求详见《售后-坏果赔付政策》。

### 第三步：给出方案（24 小时内）

根据问题性质匹配对应政策：

| 问题类型 | 处理依据 |
| --- | --- |
| 坏果、腐烂 | 《售后-坏果赔付政策》按比例赔付 |
| 延误、漏发 | 核实后补发或退款 |
| 错发、少发 | 补发缺失商品或退还差价 |
| 口味不合 | 解释品种特性，视情况赠送优惠券 |

### 第四步：结案回访（处理完成后）

确认顾客收到处理结果并表示满意，同时把本次问题记录到台账，用于后续品控改进。若同一批次的同类投诉在当天累计达到 3 起，按《客服-投诉升级机制》上报处理。
