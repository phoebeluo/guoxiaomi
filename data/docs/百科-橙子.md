# 橙子

## 产地与产季

我国橙子主产区为江西赣南、湖北秭归、重庆奉节与湖南。赣南脐橙产量最大，产季在 11 月至次年 1 月；湖北秭归因立体气候多样，实现了四季有鲜橙上市。进口橙主要来自美国加州与澳大利亚，在国内夏季填补供应空缺。

## 营养价值

橙子是维生素 C 的优质来源，一个中等大小的橙子基本可满足成人一天的维生素 C 需求。同时富含类黄酮、膳食纤维与钾。果肉表面那层白色橘络含有一定的生物类黄酮，完全可以一并食用，不必刻意剔除。热量中等偏低，每 100 克果肉约 47 千卡。

## 如何挑选

掂重量，同等大小手感更沉者汁水更足。看果皮，表面毛孔细腻、着色均匀者皮薄肉多，粗糙厚皮者通常水分偏少。按压手感紧实有弹性者为佳，过软说明存放较久。民间流传以果脐大小区分"公母"来判断甜度的说法并没有科学依据，果脐只是果实发育过程中的副产物，与风味并无直接关联。

## 保存与禁忌

常温置于阴凉通风处可保存约一周，放入冰箱冷藏 0 至 4℃ 可延长至 2 至 3 周，但冷藏后果皮可能略微变软，建议食用前取出回温片刻。切开的橙子需包上保鲜膜冷藏并在 2 天内吃完。橙子虽富含维生素 C，但含糖量并不低，建议每日食用 1 至 2 个即可，**过量食用可能导致胡萝卜素在体内沉积**，使手心脚心皮肤略微发黄，停止食用后可自行恢复；血糖偏高人群适量为宜。
