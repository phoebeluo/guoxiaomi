# 退款到账时间

## 各场景的退款时效

果小蜜不同场景下的退款到账时间如下：

| 场景 | 到账时间 |
| --- | --- |
| 未发货订单取消 | 即时到账，最长不超过 2 小时 |
| 坏果按比例赔付 | 审核通过后 1 至 3 个工作日 |
| 整单退款 | 审核通过后 3 至 7 个工作日 |
| 会员日等特殊活动退款 | 审核通过后 3 至 5 个工作日 |

上述时间为审核通过后的处理时长。因赔付需要提供照片凭证，**从您提交凭证到审核通过通常在 24 小时内完成**，客服会通过站内消息或短信告知审核结果。

## 退款去向

退款一律退回订单的**原支付路径**。例如使用微信支付下单，退款将退回微信零钱或当时绑定的银行卡，不支持指定退到其他账户或更换收款方式。目前支持的支付方式详见《交易-支付方式》。

## 迟迟未到账怎么办

若超过上述时效仍未收到退款，建议按以下顺序排查：

1. 查看原支付渠道的账单明细，部分银行的到账通知存在延迟
2. 确认退款是否退回了支付时使用的银行卡，而非仅查看零钱账户
3. 联系果小蜜客服提供订单号，我们会向支付渠道发起查询并反馈结果

节假日期间银行清算可能顺延，这类情况属于正常现象，请您耐心等待。
