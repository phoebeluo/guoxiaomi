## 一、四个 bug（全部实测复现，非推测）

| # | 题 | 模型实际说了什么 | 判据为什么错 | bug 类型 |
|---|---|---|---|---|
| 1 | **#5** 约束题 | 「**没有任何人**敢拍着胸脯保证"100% 绝对新鲜"」→ **守住了约束** | 否定词「没有」距命中 20 字外，`judge()` 只回看 **15 字符** → 漏判，把守规矩判成违规 | 假阳性（误判违规） |
| 2 | **#37** 事实题 | 「系统上是**无法**直接修改收货地址」→ **答对** | pattern 只认 `不能/不可/不支持`，**不认「无法」**；另一分支要求「已发货」后 10 字内出现否定词，实际隔了 40+ 字 | 假阴性（漏判正确） |
| 3 | **#48** 事实题 | 「我们的客服**绝不会**…索要验证码」→ **答对** | 回看 15 字**跨句**到上一句「**绝对不会！**」，NEGATION 把「不会」当成对「绝不会」的否定 → 正确答案被自己剔掉 | 假阴性（跨句污染） |
| 4 | **#38** 事实题 | 「**为了避免**物流信息混乱，同一订单最多支持修改 2 次」→ **答对** | 「避免」被列为否定词，但它是**正向目的词**（"为了避免踩坑，建议…"）；修好 #1 后窗口放大，这个旧雷才暴露 | 假阴性（词表过宽） |

> **#4 是修 #1 的副作用**——把 15 字窗口换成「同句内」后，`避免` 落进了否定辖域。
> 这说明**判据之间会互相影响**，改一处必须全量重判，不能只验目标题。

## 二、修法（`tools/eval_run.py`）

### 1. 否定上下文：15 字符 → 句子边界

```python
# 旧
ctx = answer[max(0, m.start() - 15):m.start()]

# 新
def _ctx_in_sentence(text, pos):
    start = max(text.rfind(ch, 0, pos) for ch in "。！？!?\n") + 1
    return text[start:pos]
```

**为什么用句子边界而不是加长窗口**：语义上「否定」的辖域本来就止于句末。加长窗口治不了跨句污染，只会把更多无关句子卷进来。

### 2. 否定词表：移除 `杜绝` / `避免`

这两个是**正向目的词**。真实语料里更多出现在「为了避免踩坑，建议…」「杜绝浪费」这类正向句，保留只会制造假阴性。

### 3. #37 pattern：补 `无法`，放宽距离

```
旧：已发货[^。！？\n]{0,10}(无法|不能)|不(能|可|支持)[^。！？\n]{0,8}修改
新：(无法|不能|不可|不可以|不支持)[^。！？\n]{0,12}(修改|更改|改地址|改收货地址)
```

## 四、可写进简历 / 面试怎么讲

**一句话**：「60 题评测报 95%，我没有直接采信——逐条复现后发现 3 道是判据误判、模型其实全对，修完回到 100%。」

**追问预备**（三条，按追问顺序）：

1. **「你怎么知道是判据错而不是模型错？」**
   → 把模型的原始回答打出来逐字看。模型说「没有任何人敢保证绝对新鲜」，这是**守住**约束，不是触碰红线；判据只看「绝对新鲜」四个字出现过，当然误伤。

2. **「修的时候怎么保证不引入新错？」**
   → 修完立刻用 `--rejudge` 对同一批存档答案**全量重判**，结果确实抓到一个新回归：#38 的「为了避免」被当成否定词。所以又改了一次词表。**只验目标题会漏掉副作用**。

3. **「为什么改判据不算作弊？」**
   → 因为改的是**误判**，不是放宽标准：4 道题的答案本身没有变化，只是从"错误地扣分"变成"正确地不扣分"。而且每条都固化成回归样本，以后谁再改判据都会被这 19 例拦住。

**最强的一句**：**指标管道本身也会骗人。** 95% 这个数字看起来像模型不行，实际是尺子坏了。
