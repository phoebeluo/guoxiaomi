## 三、切分崩了，根因不是内容，是超长句

对 19 篇跑 `chunk.py --dir`：

| 指标 | 现有 45 篇 | 小样 19 篇（修正前） | 标准 | 判定 |
|---|---|---|---|---|
| 中位句长 | 25 | 34 | — | 偏长 |
| P90 句长 | 50 | **79** | — | 偏长 |
| 平均块长 | 330.1 | **404.2** | 250–400 | ❌ 超 |
| P95 块长 | 398 | **889** | ≤ 450 | ❌ **近 2 倍** |
| 空块 | 0 | 0 | 0 | ✅ |

追下去，超 450 字的块只有 5 个，但最大的 **1817 字**。根因：

> **最长单句 1,725 字**（现有语料最长句只有 112 字）。

这类文章里有大段无标点的编号串和英文段落，`split_sentences` 按 `。！？\n` 根本切不开，
一句就撑爆一个块。**这正是 W1 记在「已知问题」里的那条：**
> 「单句 > 400 字符时会产出空块（已扫描全语料，0 处命中，**暂不触发**）｜W3 扩语料后复核」

复核结果：触发了，而且不是产空块，是产超长块。计划第 151 行早写好了这个分支：
> 「明显变短 / 异常 → **先扩 `split_sentences` 规则，再批量投入**」

## 四、修法：`MAX_SENT = 180` + 二次切分

```python
MAX_SENT = 180     # 现有语料最长句 112，留约 60% 余量

def _hard_split(sentence, limit):
    if len(sentence) <= limit: return [sentence]
    for piece in re.split(r'(?<=[，；、,;])', sentence):   # 先按逗号分句
        while len(piece) > limit:                          # 连逗号都没有才硬切
            out.append(piece[:limit]); piece = piece[limit:]
```

**阈值为什么是 180**：必须 > 现有语料最长句（112），才能保证旧语料**一个句都不动**；
又要 < CHUNK_SIZE（400），才能在块被撑爆之前拦住超长句。180 是这两个约束之间的安全值。

## 五、来源：四条路全部走不通（实测）

| 尝试 | 结果 |
|---|---|
| 食品伙伴网（唯一可批量抓） | 内容全是行业新闻，**不对口** |
| 农产品质量安全网「科普宣传」栏目 | 文章 90% 是**微信公众号链接** |
| └ 公众号 `mp.weixin.qq.com` | 200 但正文只 **153 字**（3.4 MB HTML，正文 JS 注入）→ 抓不到 |
| └ 站内老文章链接 | **404**（2023 年的链接已失效） |
| 百度百科 / 搜狗百科 / 维基 | 403 / JS 渲染 / 不可达 |
| 京东帮助 / 惠农网 / 下厨房 | JS 渲染 / 要登录 |
| 国标平台 | 可抓，但条款型，量只够 20–30 篇 |

**根本问题**：果小蜜要的是「消费者视角的水果知识」（品种、挑选、保存、禁忌），
这类中文内容的载体恰好是百科、公众号、生活媒体——**全部有反爬或 JS 渲染**；
而能抓的政府站与行业站，写的都是新闻与公文。

## 六、需要拍板：三条路

| 方案 | 做法 | 代价 | 我的判断 |
|---|---|---|---|
| **A · 噪声路线** | 把可抓的食品行业语料（228 条 × 多页，够 400+）作为**检索噪声**，W4 仍按 45/150/400 测衰减 | 结论表述要改：测的是「异构语料的噪声容忍度」，不是「同类知识变多后的衰减」 | **推荐** |
| B · 缩规模 | 只做对口量：国标 20 + 质量安全网若干 → 45 → 90 篇，三档改 45/70/90 | 规模太小，衰减实验说服力弱 | 次选 |
| C · 上无头浏览器 | Playwright 抓公众号 / 百科（绕过 JS 渲染） | 1–2 天工程 + 版权与 ToS 风险 | 不推荐 |

**为什么推荐 A**：W4 测的是**规模**（全量注入时的 lost-in-the-middle），不是「知识增量」。
355 篇同域噪声（食品/农产品，与果小蜜共享「农残、保质期、冷链」等词汇）完全能触发干扰；
而且真实生产环境的知识库本来就是混杂的。**代价只是结论怎么写，不是实验做不做。**

⚠️ 选 A 必须同时定三条硬规则（否则 `gold_sources` 会被污染）：
1. 外部语料只进 `百科/品类/成分/标准` 域，**禁止**出现别家的运费门槛/会员规则/赔付比例
2. 文件名统一 `行业-` 前缀，与自有 45 篇在文件名上就能分开
3. 抓完跑一次冲突扫描，命中自有专有事实的**整篇剔除**
