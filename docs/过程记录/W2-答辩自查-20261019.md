# W2 答辩自查清单（2026-10-19）

> 用途：把 W2 做过的事，逐条转化为「你本人能讲清」的能力项。  
> 定稿标准：每条能**不看文档、用自己的话说满 60 秒**，且能指出证据文件。

## 一、先划清界限：哪些是机械，哪些是能力

| W2 里的动作                               | 实际谁做的                | 面试会问吗             |
| ------------------------------------- | -------------------- | ----------------- |
| 建文件、写 Markdown、粘贴规则                   | AI                   | 不会                |
| 批量往 `cases.jsonl` 写 `gold_sources` 字段 | AI（按候选表机械写入）         | **会问「你凭什么叫金标」**   |
| 60 题的**金标候选**判断                       | AI 先出草案，你只做了 3 项口径裁决 | **会问，且是重灾区**      |
| 3 项口径裁决（`source` 去留 / 7:2:1 / 多轮锚定末轮） | **你本人**              | **会问，这是你的**       |
| 改 `eval_run.py`、修 4 处判据 bug           | AI                   | **会问「判据怎么保证不误判」** |
| 划留出集 8 题                              | AI 出名单，你未逐题复核        | **会问「为什么留这 8 题」** |

**诚实结论**：W2 的「判断类」工作有约 60% 是 AI 代做的（金标草案、留出集名单、判据修法）。这正是你担心的部分，且担心得对。

## 二、必须能讲清的 8 件事（每条给了标准答案骨架）

### 1. 什么是「金标」

- **一句话**：评测时用来判断「答案是否真的有依据」的那篇（或几篇）文档。
- **为什么必须每篇指定**：不指定，就无法区分「模型答对了」和「模型蒙对了」。
- **关键细节**：`gold_sources` 是**列表不是字符串**，因为一题答案可能散在多篇里。
- **证据**：`eval/cases.jsonl`、`docs/金标规则说明-20261015.md` 第二节。

### 2. `source` 和 `gold_sources` 为什么要并存

- `source`：给人看的描述（可自由写「语料中无此信息」）。
- `gold_sources`：给程序读的篇目列表（只写文件名，不写路径）。
- **为什么不能合并**：人话和机器口径混在一个字段里，改描述就会悄悄改变评测结果。
- **证据**：`金标规则说明` 第三节字段表。

### 3. `has` / `none` / `constraint` 三态与金标的硬对应

- `has` → `gold_sources` **必须非空**；
- `none`（语料没有，不得编造）、`constraint`（红线，依据在 system prompt）→ **必须是 `[]`**。
- **一句话考点**：`has` 而金标为空 = 标注错误，运行器会报出来。

### 4. 一题算「1 篇」还是「多篇」怎么判

- 判据&#x662F;**「该文档能否独立支撑 pattern 所需的具体事实」**，不是「话题相关」。
- 反例：文档只提到"运费"但没写具体门槛 → 不算。
- **多篇的真实来源**：`售后-常见问题汇总.md` 是「答案富集篇」，它复述了时效、快递、运费、自提、溯源多处答案，所以 12 道多答案题里多数含它。

### 5. 7:2:1 是什么、为什么是它

- 可回答 : 多答案 : 库外 = **42 : 12 : 6**（精确命中）。
- **为什么**：只用单篇会的问题测不出「多文档检索 + 融合」；全用库外题测不出「答对」能力。三条轴对应三种失效模式：答不出 / 整合不好 / 编造。
- 这是**你本人裁决**的口径，不是 AI 定的。

### 6. 留出集（holdout）为什么划、怎么用

- **为什么**：调参期间反复看同一批题，会无意中把这批题"调"到过拟合；留出集就是**封存到最后的考卷**。
- **纪律**：W3–W8 所有调参必须带 `--no-holdout`（只跑 52 题）；留出 8 题只在 W13 最终汇报时跑一次。
- **为什么必须在判据定稿后划**：判据带 bug 就冻结题库，等于把错误刻进最终数字。
- **证据**：`docs/过程记录/留出集清单-20261019.md`、`eval_run.py --no-holdout`。

### 7. 那 4 个判据 bug（**这是你最好的面试素材**）

核心论点：**判据本身也是被测对象，也要有回归测试。**

- **#5**：模型说「没有任何人敢保证 100% 绝对新鲜」——守住了约束，但否定词「没有」距命中 20 字，旧实现只回看 15 字符 → **守规矩被判成违规**（假阴性）。
- **#37**：模型说「系统上是**无法**直接修改收货地址」——答对了，但 pattern 只认 `不能/不可/不支持`，**不认「无法」**。
- **#48**：正确答案被**上一句**的「绝对不会！」污染——回看窗口跨了句。
- **#38**：修完前三个后，窗口放大导致「为了**避免**物流混乱」里的「避免」被当成否定词 → **修 bug 的副作用**。
- **最值钱的一句**：**判据改动必须全量重判**，只验目标题会漏掉副作用（#38 就是这么暴露的）。
- **修法**：否定上下文从「固定 15 字符」改为「**到句子边界**」；从否定词表移除 `避免`/`杜绝`（正向目的词）。
- **结果**：报告数字 95% → 离线重判 **60/60 = 100%**，API 调用为 0。
- **证据**：`docs/过程记录/判据修正记录-20261019.md`、`tools/test_judge.py`（19 例回归）。

### 8. 可比性纪律（一句话红线）

- **题库一变，历史数字全部作废；语料一变，本次评测作废。**
- 所以 W2 定型后**不中途加题**；确需加题必须另存版本号，不覆盖。
- 同样，对外只能引用 `w2_cases60_gold_rejudged.md`（100%），**不能用旧的 95% 那份**。

## 三、三个必须亲手过一遍的动作（约 20 分钟，零成本）

> 不做这一步，"会"只是听懂，不是会。

1. **抽一题自己重标金标（10 分钟）**  
   打开 `eval/cases.jsonl` 找 `#46`（3 篇金标那条），记下它问什么，然后去 `data/docs/` 里**逐篇搜原句**，确认那 3 篇是不是每篇都独立支撑。若你判断有 1 篇不该算 → 你就真正掌握第 4 条。
2. **跑一次隔离（2 分钟）**
   ```
   .venv\Scripts\python.exe tools\eval_run.py --check --no-holdout
   ```
   看懂输出里「留出集 8 题」被排除的动作，以及 52 这个数字怎么来的。
3. **亲手制造一次假失败再修好（8 分钟）**  
   把某题 `pattern` 改成一个**必然匹配不到**的正则 → 跑 `--rejudge` 看它变成失败 → 改回来 → 再跑回 100%。  
   目的是亲眼看到：**判据错了，模型答对也会被判失败**。这是第 7 条的内核。

## 四、从 W3 起改工作方式（防止再欠债）

| 环节             | 谁做    | 铁律                        |
| -------------- | ----- | ------------------------- |
| 语料来源清单 / 取舍    | **你** | AI 只列候选与理由，你拍板            |
| 爬取脚本、切分代码      | AI    | 你只需能讲清「为什么要两级抓取」「切分按什么边界」 |
| 判据 / 金标 / 题目答案 | **你** | AI 只做格式落库                 |
| 跑命令、看输出        | **你** | AI 给命令和「期望看到什么」           |
| 结论与数字解释        | **你** | 讲不满 3 分钟的数字，直接删掉          |

一句话：**AI 负责让事情变快，你负责让事情变成你的。**

## 五、诚实边界：现在还不能讲、需要补的

| 还不能讲的                          | 补的时机                |
| ------------------------------ | ------------------- |
| 这 60 题的金标为什么逐题这么定（只做过 3 项口径裁决） | 用第三节动作 1 的方式抽 5 题自检 |
| 留出集那 8 题的逐题理由                  | 读 `留出集清单` 后自己重述一遍   |
| BM25 / RRF / 向量检索（W6–W7）       | 到对应周再学，现在不必         |
| FastAPI / 服务化（W9+）             | 同上                  |

**结论**：W2 你缺的是「逐题判断的所有权」，不是「全部知识」。用第三节 20 分钟 + 第二节 8 条，就补得上；而且这 8 条里第 7 条（判据误判）的含金量，比"自己敲代码"更高——**大多数候选人说不出"我的评测器自己错了 4 次"**。
