## 一、发出去的话（直接复制）

> 帮我个忙，5 分钟。
>
> 我在做一个水果店的客服助手（不是真人，是 AI），现在需要真人来问它问题，
> 看它在真实问法下会怎么答。**重点是挑毛病，答得不好才有用**。
>
> 电脑上打开这个链接：`http://localhost:8501`（我这边开着，你连同一个 WiFi 就行；
> 不行我把电脑给你）
>
> 随便问 3–5 个你买水果时真会问的问题，比如「这个甜不甜」「坏了怎么赔」
> 「多久能到」「能不能便宜点」。
>
> 问完把下面这段填一下发我：
>
> ```
> 1. 你问了什么：
> 2. 它答的哪里不对 / 哪里怪：
> 3. 满分 5 分你打几分：
> ```
>
> 不用客气，骂得越具体越有用。谢谢！

**为什么这么写**：明确要「挑毛病」、给出真实问题示例、把反馈压缩成 3 行。
让人写长反馈，回收率会掉一半。

## 二、你自己要准备的两件事（10 分钟）

### ① 启动

```
cd /d E:\guoxiaomi
.venv\Scripts\activate
streamlit run app.py
```

窗口里会显示 `Local URL: http://localhost:8501` 和 `Network URL: http://192.168.x.x:8501`。

**把 Network URL 发给同学**，他们在同一个 WiFi 下能直接打开。
`localhost` 只有你自己能开。

### ② 记录表

新建一个表格（腾讯文档/Excel 都行），列就这几列：

| 编号 | 谁 | 问了什么 | 原话回答（截图或复制） | 问题类型 | 是模型错还是检索错 | 修没修 |
|---|---|---|---|---|---|---|

`问题类型` 只填这五类之一，别自己发明：

| 类型 | 判定 |
|---|---|
| **答错** | 有明确正确答案，它答错了 |
| **编造** | 库里没有，它却给出了具体事实（价格/时效/政策） |
| **拒答不当** | 库里有答案，它说「查不到」 |
| **答非所问** | 答案本身没错，但不是人家问的 |
| **体验差** | 事实都对，但太长/太硬/太像机器人 |

## 三、5 组多轮验证（你自己做，20 分钟）

题库里只有 7 道多轮题且不宜再加（定型纪律），所以这块只能人工补。
每组 3 轮，**记录下来它是否还记得上一轮**。

| 组 | 考什么 | 三轮怎么说 | 合格标准 |
|---|---|---|---|
| **1 追问** | 能不能接着上文答 | ①「车厘子多少钱」②「那两斤呢」③「有没有优惠」 | 第②轮知道「那」指车厘子，第③轮不重复问品种 |
| **2 改口** | 能不能跟着改 | ①「我想买苹果」②「算了还是要车厘子」③「刚才那个多少钱」 | 第③轮答车厘子，不是苹果 |
| **3 回指** | 能不能接代词 | ①「满多少免运费」②「那会员呢」③「我这个算哪种」 | 第②③轮知道在讲同一件事 |
| **4 纠错** | 会不会被带偏 | ①「你们满 200 免运费吧」②「不对，是 99 吧」③「到底多少」 | 两次都坚持 **99**（知识库口径），不附和 200 |
| **5 跨主题** | 会不会串台 | ①「坏果怎么赔」②「那榴莲怎么挑」③「回到赔付，要几天」 | 第③轮能切回赔付，且不把挑榴莲的建议混进来 |

**第 4 组是重点**：它和 W11 抓到的那条对抗绕过是同一类问题（附和顾客口述）。
如果这里也出现附和，说明 prompt 里那条「工具结论高于顾客口述」还没覆盖知识库场景。

记录模板：

```
组1 追问：①✓ ②✓ ③✗（第③轮又把品种问了一遍）→ 记忆在，但没利用上下文
```

## 六、口头练（3 遍，每遍 3 分钟）

挑这三条各讲一遍，**录音回放**，听到含糊指代就重讲：

1. 「我项目里检索是怎么接进去的」
2. 「b=0.75 是怎么定的」
3. 「压测发现了什么 bug」

第 3 条是 W12 新增的，也是最好讲的一条——它有完整的因果链，而且**结论是「我的 QPS 上限不在我的服务」**，
这种「我测出来一个反直觉的事」比「我压测到 1000 QPS」值钱得多。
